# Demo video script (target: 2–3 minutes)

Record the live site with backend and Hindsight online. Seed Hindsight first.

| Time | On screen | Say |
|---|---|---|
| 0:00 | Header + stats strip | "On-call engineers keep re-investigating problems their team already solved. IncidentIQ remembers." |
| 0:15 | Before/After tab, press Compare | "Same payments outage, sent twice: once with memory off, once with Hindsight recall." |
| 0:40 | Left column | "Without memory: reasonable, generic advice. Check the database, scale up." |
| 0:55 | Right column, memory panel | "With memory: it recalls incidents where the connection pool ran out after a deploy, shows match scores and dates, and recommends the exact fix that worked before." |
| 1:25 | Respond tab → analyze → resolve form | "When I resolve an incident, the root cause, fix, outcome and lessons go into Hindsight." |
| 1:50 | Submit a similar incident | "The next similar incident recalls what I just taught it." |
| 2:10 | Memory dashboard | "The dashboard shows what it has learned: recurring root causes, fixes that worked and failed, and memory-bank stats." |
| 2:30 | Close | "Resolve an incident once, and the agent remembers it. That's IncidentIQ." |

Tips: 1080p, cursor highlight on, wake the Render backend before recording (first request ~30s).
