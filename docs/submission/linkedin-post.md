Every on-call engineer knows the feeling: you're debugging an outage that
someone on your team already fixed months ago.

We built IncidentIQ, an AI incident responder with persistent memory.

🔁 Before each analysis, it recalls similar past incidents from Hindsight memory
✅ After an engineer resolves an incident, it stores the root cause, fix, outcome and lessons, including failed fixes
👀 Every answer shows which past incidents it relied on, with match scores and dates

The best part is the side-by-side demo: the same outage answered without memory (generic advice) and with memory (the exact fix that worked last time).

I worked on ___. The biggest lesson: showing the memory behind an answer is what makes engineers trust it.

Demo: https://incident-response-agent-puce.vercel.app/
Code: https://github.com/astacatalyst/Incident-Response-Agent
